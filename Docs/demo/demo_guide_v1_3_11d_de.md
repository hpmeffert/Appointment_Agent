# Demo Leitfaden v1.3.11d

## Hauptgeschichte dieses Releases

Dieses Release macht aus dem Appointment Agent ein gehostetes Demo-Paket fuer den Vertrieb.

Der wichtigste Satz ist:

- "Das ist dieselbe Appointment-Agent-Demo, aber jetzt so verpackt, dass sie als stabile Docker-Umgebung mit eigenem Datenbankverhalten gehostet werden kann."

## Story 1: Gehostetes Cockpit zeigen

- kombiniertes Cockpit oeffnen
- Dashboard, Message Monitor, Reminder und Addresses zeigen

Was du sagen kannst:

- "Der Operator hat eine gehostete Cockpit-URL und kann trotzdem die komplette Demo-Story zeigen."

## Story 2: Sichere Demo-Defaults zeigen

- Google Demo Control oeffnen
- Simulations-Defaults zeigen
- erklaeren, dass die gehostete Demo nicht sofort Produktiv-Integrationen braucht

Was du sagen kannst:

- "Die gehostete Demo ist zuerst auf Verlaesslichkeit und danach auf Realismus ausgelegt."

## Story 3: Reset-Bereitschaft zeigen

- den Docker-Volume-Reset erklaeren
- erklaeren, dass die Datenbank in der Demo-Runtime enthalten ist

Was du sagen kannst:

- "Wenn eine Demo zu viel Zustand veraendert, kann das Team die Umgebung auf eine klare Weise zuruecksetzen."
