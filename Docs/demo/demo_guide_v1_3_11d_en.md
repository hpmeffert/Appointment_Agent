# Demo Guide v1.3.11d

## Main story of this release

This release is about turning the Appointment Agent into a hosted demo package for sales.

The key sentence is:

- "This is the same Appointment Agent demo, but now packaged so it can run as a stable Docker-hosted environment with its own database behavior."

## Story 1: Show the hosted cockpit

- open the combined cockpit
- show Dashboard, Message Monitor, Reminder, and Addresses

What you can say:

- "The operator has one hosted cockpit URL and can still move through the full demo story."

## Story 2: Show safe demo defaults

- open Google Demo Control
- point out simulation-oriented defaults
- explain that the hosted demo can stay safe without needing production integrations

What you can say:

- "The hosted demo is prepared to be reliable first and realistic second."

## Story 3: Show reset readiness

- explain the Docker volume reset path
- explain that the database is included in the demo runtime

What you can say:

- "If a demo changes too much state, the team can reset the environment in one clear way."
