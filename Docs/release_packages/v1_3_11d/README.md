# Release Package v1.3.11d

This directory contains the hosted demo release package documentation for `v1.3.11d`.

## Purpose

`v1.3.11d` prepares the Appointment Agent as a hosted sales demo runtime that runs inside Docker, includes its database behavior, and can later be placed onto an Azure-hosted system.
